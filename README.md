Instructions:
Select main.cpp inside src and hit the run button.

Data structure time comparisons appear when using 'Rank countries by
characteristic for a date' and are stored in the feature access log.

Rank countries by characteristic allows the user to access the top x
countries for either new or cumulative total cases or deaths from COVID.

Evaluate country growth rate allows the user to input a country, with full name
spelling (eg. United States of America) and see the percent growth for total
deaths and cases between two dates.

Viewing the feature access log shows all previous search queries and their results.

View dataset summary givers basic information about the data.

Clear feature log erases all saved searches from the feature access log.

Exit ends the program
